## Open topics

- Following the proposal, a new [`community-packages`](https://github.com/OKDP/community-packages) repository has been created. It will host community-driven packages that are not officially supported by the TOSIT organization. Community members can contribute packages here, which may eventually be integrated into the core OKDP project. Expanding this repository will help build trust with third parties interested in OKDP by demonstrating a growing ecosystem.
- Discussion regarding the structure of upcoming releases. The team proposed introducing Release Candidates (RCs) to establish a code freeze period. This will allow for thorough end-to-end testing beforehand rather than relying on last-minute testing.
- Discussion regarding delivery frequency. The team agreed that it is currently too early to commit to a fixed release schedule.
